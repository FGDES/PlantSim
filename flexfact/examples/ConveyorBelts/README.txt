=========================================================

Conveyor Belts

Example setup for the manufacturing simulator FlexFact

For an introduction to FlexFact, see

http://www.rt.eei.uni-erlangen.de/FGdes/flexfact.html

=========================================================

This is an example to run consecutive conveyor belts in FlexFact. 

Documentation of the tools relevant this example can be retrieved at:

http://www.rt.eei.uni-erlangen.de/FGdes/faudes/luafaudes/index.html
http://www.rt.eei.uni-erlangen.de/FGdes/faudes/registry/simulator_index.html
http://www.rt.eei.uni-erlangen.de/FGdes/faudes/registry/simulator_devices.html#SimplenetDevice

An elementary example to start with is provide in the folder OperatorPanel,
located next to this folder.

Disclaimer: the plant models and specifications used in this example
are functional but do need more work.
