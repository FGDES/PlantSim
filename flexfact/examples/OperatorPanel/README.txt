=========================================================

OperatorPanel

Example setup for the manufacturing simulator FlexFact

For an introduction to FlexFact, see

http://www.rt.eei.uni-erlangen.de/FGdes/flexfact.html

=========================================================

This is a very simple example for the operator panel provided FlexFact. It 
is meant to test elementary functionality of a closed-loop configuration with a 
FlexFact plant, a DESTool or simfaudes supervisor, synchronized by the Simplenet 
proptocol.

More information relevant to this example can be retrieved at:

http://www.rt.eei.uni-erlangen.de/FGdes/destool
http://www.rt.eei.uni-erlangen.de/FGdes/faudes/registry/simulator_index.html
http://www.rt.eei.uni-erlangen.de/FGdes/faudes/registry/simulator_devices.html#SimplenetDevice

To run the example, you may follow the following steps.

=========================================================

1. Start the plant simulation in FlexFact

Open the provided plant configiguration "TwoBelts.ffs" with FelxFact. In the 
"Simulation"-Menu, you can turn on the "SimpleNet (local) Device" and then start 
the simulation with the "Start"-button.  The "EventLog"-view on the right will 
indicate the network status "starting up".

Now, the simulation is running and the network node "Plant" accepts subscriptions 
to sensor events. The internal "SimpleNet" configuration sets up a network to 
consist of the two nodes "Plant" and "Supervisor". FlexFact is now trying to connect 
to the node "Supervisor" to subscribe to actuator events.

A device configuration for the node "Supervisor" can be generated by the FlexFact 
"File"-menu. For this exampe, it is already provided by the file "super_simplenet_local.dev". 
The file is human-readable for easy inspection.

Note: the Simplenet protocol supports nodes on remote hosts and implements automatic 
address resolution via UDP broadcasts. However, to avoid issues with firewalls 
and partly loaded network stacks, it is reommended that you begin with a configuration 
where all nodes reside on the local machine. Here, static addresses are set by 
choosing the "(local)" variant of the Simplenet setting. 


=========================================================

2a. Start the supervisor simulation with simfaudes

The simulator "simfaudes" is a command-line tool provided with libFAUDES. An executable 
should also be included in the binary package of FlexFact. To start the simulation, 
run

simfaudes -d super_simplenet_local.dev super.gen

from the command line. Assuming you cd to the example directoty, you must preceed 
"simfaudes" with the full path (location depends on your set-up, typically next to 
the FlexFact executable).

The "-d" option configures event synchronisation via a device specified by 
"super_simplenet_local.dev". For the provided file, this amounts to a Simplenet network 
with node "Supervisor" providing exactly those events for which the plant simulation 
wants to subscribe and vice versa.

Console output should indicate that simfaudes has connected to the node "Plant" 
and awaits events to be executed. At the same time, FlexFact should indicate in the 
"EventLog"-view that it changed its status from "starting up" to "up and running".

If you experience the connection to fail, the most likely reason is a personal firewall. 
Windows and Mac OSX may prompt for your or the administrators permission to allow 
simfaudes/FlexFact/DESTool to perform network operations. If not, you may need to 
manually configure your firewall. Relevant ports are TCP 40000, TCP 400001 and 
UDP 40000. For a quick test, you may also consider to **temporarily** turn off the 
firewall.

=========================================================

2b. Starting the supervisor simulation with DESTool

Open "OperatorPanel.pro" with DESTool. The project consists of one automaton only, 
used as the supervisor. 

Go to the "Animation"-tab in the project Browser. On the bottom of the tab, there 
is a "Configure"-Button. Use this to set the IO-Device to the device file "super_simplenet_local.dev". 
The file was automatically generated by FlexFact and matches the given plant. It 
defines the Simplenet node "Supervisor" and configures how individual events are 
communicated.

You can now start the device by the "Start"-button (also on the "Animation"-tab). 
The device status goes from "down" to "starting up" and now searches for the missing 
node "Plant". Provided you have started the plant simulation by FlexFact as described 
in above step 1, the status will change to "up and running". This indicates that both, 
FlexFact and DESTool have agreed on how to synchronize events. See the last paragraph 
of above step 2a for possible issues at this stage.

When the network is "up and running", you van start the actual simlation of the 
supervisor by the buttons "Init" and "Exec" from the "Animation"-tab. The default 
amounts to a simulation of 100 transitions and can be adjusted in the text field next 
to the "Exec" button.


=========================================================

3. Inspect the closed-loop behaviour

Once the connection is up and both, plant and supervisor simulation, are running, 
the closed loop is operational. By the provided supervisor dynamics, nothing will happen 
until you press the operator panel button OP_x1. Doing so, you will observe the event 
"op_s1act" being transmitted from FlexFact to DESTool/simfaudes and executed by the 
supervisor. The successor state has the event "op_l1on" enabled, which will be 
executed immediatly and transmitted to FlexFact. Observe the operator panel button 
OP_x1 to become illuminated.

Play allong with the buttons OP_x1 and OP_x2 to observe the effect on the plant.
